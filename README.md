# Lexis

Локальное офлайн-приложение — личный трекер: английские слова, дни и привычки.
Go + Svelte 5 + PostgreSQL, всё в Docker. Работает на http://localhost:8090.

## Разделы

Сверху — разделы, слева — их подразделы. Адрес страницы живёт в `#/раздел/подраздел` (закладки и «назад» работают).

| Раздел | Что внутри |
|---|---|
| **Английский** | Новые (ввод слов) · Группы · Тренировка (интервальные повторения, 5 уровней) · Статистика · Настройки (лимит новых слов, импорт/экспорт слов) |
| **День** | День (оценка 1–10, дофаминовая шкала из 7 квадратиков, «что классного сделал», рассказ) · Календарь месяца · Неделя (анализ «о чём → вывод» + сводка) · Статистика (графики оценки и дофамина, выполнение привычек) |
| **Привычки** | Отметки за день · Календарь (неделя/месяц, цели полосами) · Цели на период · Наблюдения и выводы · Мои привычки |
| **⚙** (справа в шапке) | Общие (язык) · Данные (полный бэкап, восстановление, «Очистить всё») |

Напоминания — только внутри приложения: после 18:00 на «Дне» точка, если день не оценён; на «Привычках» — сколько позитивных привычек сегодня не отмечено.

Полная спецификация — [docs/SPEC.md](docs/SPEC.md).

## Требования

- Docker Desktop
- Python 3 (для `run.py`, только стандартная библиотека)
- Для разработки: Go 1.27, Node.js ≥ 22.12, [sqlc](https://sqlc.dev) (для перегенерации запросов)

## Запуск и управление

Все команды — из корня проекта.

| Команда | Что делает |
|---|---|
| `python3 run.py` | То же, что `up`: поднять контейнеры и дождаться готовности |
| `python3 run.py up --build` | Пересобрать образ (после изменений в коде) и поднять |
| `python3 run.py up --open` | Поднять и открыть в браузере |
| `python3 run.py down` | Остановить контейнеры (данные сохраняются) |
| `python3 run.py restart` | Перезапустить |
| `python3 run.py logs` | Логи всех контейнеров (follow) |
| `python3 run.py logs app` / `logs db` | Логи приложения / базы |
| `python3 run.py status` | Состояние контейнеров и API |

Docker Desktop не запущен — `run.py` запустит его сам. При первом запуске `.env` создаётся из `.env.example`.

## Данные

- База лежит в Docker-volume `lexis_pgdata`: `down`, `restart` и `up --build` её **не трогают**.
- Удаляет данные только `docker compose down -v` или удаление volume вручную — не делай этого без бэкапа.
- Бэкап: **⚙ → Данные → Скачать полный бэкап (JSON)** — всё: слова, дни, недели, привычки, настройки.
  Восстановление: **⚙ → Данные → Восстановить** — заменяет разделы, которые есть в файле (старый бэкап без дневника и привычек их не тронет).
- Очистка: **Английский → Настройки → Очистить английский** (дни и привычки остаются) или **⚙ → Данные → Очистить всё**. Настройки остаются в обоих случаях.
- Незавершённая тренировка (закрыл страницу посреди сессии) в статистику не попадает; уровни уже отвеченных слов сохраняются.
- Дни и привычки записываются за сегодня и прошлые даты, в будущее — нельзя. «Сегодня» — по `TZ` из `.env`.

## Настройки окружения (`.env`)

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `LEXIS_PORT` | `8090` | Порт на хосте (8080 занят другим проектом) |
| `TZ` | `Europe/Moscow` | Таймзона: от неё зависят «сегодня», статусы групп, серии дней |
| `POSTGRES_DB` / `POSTGRES_USER` / `POSTGRES_PASSWORD` | `lexis` | Доступ к базе (наружу не торчит) |

## Формат ввода слов

Одна строка — одна карточка, **Английский → Новые**:

```
слово || перевод || пример1 <> пример2 || #группа1 #группа2
```

```
apple || яблоко || I eat an [apple] every day || #еда
go_went_gone || идти || I [go] home <> I [went] home <> I have [gone] home || #глаголы
by bus || на автобусе || I go to work [by bus] || #фразы
```

- Примеры и группы необязательны: `apple || яблоко` — уже карточка.
- Несколько примеров — через `<>`, выделяемое слово — в `[скобках]`.
- Три формы глагола — через `_`; дефис — часть слова (`well-known`).
- Группы — с `#` или без, через пробел или запятую.
- Пустые строки и строки с `//` пропускаются. Повтор того же слова с тем же переводом не создаёт дубль, а добавляет примеры и группы.

Импорт файлом (**Английский → Настройки → Импорт**): CSV с колонками `term,translation,example,tags` или JSON `[{"term","translation","example","tags"}]`.

## Горячие клавиши

| Где | Клавиша | Действие |
|---|---|---|
| Английский → Новые | `⌘/Ctrl + Enter` | Создать карточки |
| Тренировка | `Enter` / `Пробел` | Показать ответ |
| Тренировка | `1` / `2` / `3` | Знаю / Затрудняюсь / Не знаю |
| День → Дофамин | `Enter` / `Esc` | Сохранить / закрыть квадратик |
| День → Неделя, Привычки → Отметки | `⌘/Ctrl + S` | Сохранить |
| Привычки → Наблюдения | `⌘/Ctrl + Enter` | Добавить запись |

## Разработка

### Бэкенд (`backend/`)

```bash
cd backend
go build ./...
go vet ./...
go test ./... -race          # unit-тесты, без БД
sqlc generate                # после изменений в queries/*.sql или migrations/
```

Интеграционные тесты — на отдельной временной базе (порт 5444; тесты сбрасывают схему):

```bash
docker run --rm -d --name lexis-testdb -p 127.0.0.1:5444:5432 \
  -e POSTGRES_USER=lexis -e POSTGRES_PASSWORD=lexis -e POSTGRES_DB=lexis_test postgres:17-alpine
LEXIS_TEST_DSN='postgres://lexis:lexis@127.0.0.1:5444/lexis_test?sslmode=disable' \
  go test -tags integration -p 1 ./... -race
docker stop lexis-testdb
```

`-p 1` обязателен: все пакеты используют одну тестовую базу.

### Фронтенд (`frontend/`)

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173, /api проксируется на бэкенд (:8090)
npm run check    # svelte-check (типы, a11y; предупреждения = ошибки)
npm test         # vitest — чистая логика
npm run build    # сборка в dist/
```

Бэкенд на другом адресе — `LEXIS_API_URL=http://127.0.0.1:XXXX npm run dev`.
Vite слушает `localhost` (на macOS это IPv6) — открывай `localhost:5173`, а не `127.0.0.1:5173`.

### Отладка бэкенда в VS Code

1. В `docker-compose.yml` раскомментируй `ports` у `db` (`127.0.0.1:5436:5432`).
2. `docker compose up -d db`
3. F5 — конфигурация «lexis server» (сервер на `:8090`, база на `5436`).
4. Фронт — `cd frontend && npm run dev`.

Контейнер `app` при этом должен быть остановлен (`python3 run.py down` и затем `docker compose up -d db`), иначе порт 8090 занят.

### Сервер без Docker

```bash
cd backend
LEXIS_HTTP_ADDR=:8090 \
LEXIS_DB_DSN='postgres://lexis:lexis@127.0.0.1:5436/lexis?sslmode=disable' \
LEXIS_TZ=Europe/Moscow \
go run ./cmd/server
```

`lexis healthcheck` — проверка `/healthz` (exit 0/1), её использует healthcheck контейнера.

## Если что-то не так

| Симптом | Что проверить |
|---|---|
| `run.py up` ждёт и падает по таймауту | `python3 run.py logs app` — обычно ошибка подключения к БД или занятый порт |
| Порт 8090 занят | Поменяй `LEXIS_PORT` в `.env` и перезапусти |
| На странице «frontend is not built» | Бинарник собран без фронта — `python3 run.py up --build` |
| В браузере «Сервер недоступен» при `npm run dev` | Бэкенд не запущен или не на :8090 |
